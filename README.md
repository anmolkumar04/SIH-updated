# YatraBharat 🇮🇳

### Explore India. Discover its culture. Plan your journey.

YatraBharat is a smart tourism web platform designed to help travelers explore destinations across India. It brings together destination information, attractions, local cuisine, accommodation suggestions, travel tips, and regional phrases in one interactive experience.

> **Project:** YatraBharat — All States SIH Smart Tourism Platform

## ✨ Features

- **Explore Indian destinations:** Browse state- and union-territory-focused travel information.
- **Tourist attractions:** Discover places to visit, with categories, estimated visit durations, entry-cost information, ratings, and map coordinates.
- **Local food discovery:** Learn about regional dishes, descriptions, spice levels, and ratings.
- **Accommodation suggestions:** Browse hotels with location, price-per-night, category, and rating information.
- **Interactive maps:** View destinations using Leaflet maps.
- **Travel tips:** Read destination-specific do's and don'ts.
- **Useful local phrases:** Find common greetings and phrases with translations and usage notes.
- **Responsive, dark-themed interface:** Styled with Tailwind CSS and custom glass-like cards.
- **Motion and icons:** Uses Framer Motion for animations and Lucide icons for interface visuals.

## 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS | Custom styling |
| Tailwind CSS | Utility-first styling |
| JavaScript | Application logic |
| React 18 | UI components and state |
| Babel Standalone | In-browser JSX transformation |
| Leaflet | Interactive maps |
| Framer Motion | UI animations |
| Lucide | Icons |

The current project loads its frontend libraries through CDN links and is implemented in a standalone HTML file.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Internet connection (the page loads its libraries and map assets from CDNs)

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Open `index.html` in your browser.

   Alternatively, run a local static server from the project directory:

   ```bash
   python -m http.server 8000
   ```

   Then visit [http://localhost:8000](http://localhost:8000).

## 🗺️ How to Use

1. Open the website.
2. Browse or select a destination.
3. Explore attractions, local food, accommodation suggestions, and travel guidance.
4. Use the map and destination details to help plan your trip.

## ⚠️ Notes

- Destination details, prices, ratings, weather descriptions, and travel guidance are provided as displayed by the project and may not reflect current conditions.
- Verify entry fees, hotel prices, permits, opening hours, and local rules with official sources before traveling.
- An internet connection is needed to load externally hosted libraries, map resources, and images.
